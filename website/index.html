Smart Extraction

Structured data out of
any document type

A two-path pipeline that chooses the right tool for every document — PaddleOCR for scanned pages, embedded text for digital PDFs, Gemma4 for understanding both.

01
Detect document type automatically
PyMuPDF reads the embedded text layer. More than 200 characters → structured digital PDF. Fewer → scanned image. No configuration needed.
02A
Digital PDF path — embedded text + image
For payslips, bank statements, and offer letters: embedded text gives exact values; the page image gives layout context. Both are sent to Gemma4 together.
02B
Scanned path — PaddleOCR + coordinates
For marksheets, degrees, and identity documents: PaddleOCR runs at 3× zoom, extracts text with pixel-level bounding boxes, and passes coordinates to Gemma4 so column pairing is accurate.
03
LLM extraction + validation + retry
Gemma4 returns structured JSON. A domain rule pack validates arithmetic, required fields, and format patterns. If confidence is LOW or validation fails, Gemma4 is retried once with a correction prompt.

Live Video KYC

Remote liveness verification —
no app, no plugin required

Create a session, share a URL. The customer opens it on their own device. Active liveness challenges run over a WebSocket with ArcFace face matching built in.

🔗
Share a secure URL
Operator clicks "Create KYC Session." A 30-minute session is created and a shareable link is returned. Send it by email or WhatsApp — no install required on the customer's side.
👁️
Active liveness over WebSocket
The browser streams JPEG frames every 310 ms. Blink uses MediaPipe EAR (Eye Aspect Ratio). Turn-left and turn-right use nose relative position. Nod uses pitch range over 6+ frames.
🤝
ArcFace identity match
If an ID document was uploaded at session creation, InsightFace extracts a 512-dimensional face embedding. After liveness passes, ArcFace cosine similarity is computed against the live frame. Threshold: 0.40.
📋
PDF audit report on save
Operator clicks "Save to Database." A PDF is generated with the full verdict, liveness timeline, face match metrics, and PASS/FAIL box — stored in PostgreSQL and downloadable immediately.

Document Intelligence

From raw scan to
actionable intelligence

Every approved document feeds a structured intelligence layer — extracted fields, fraud signals, cross-document comparisons, and full layered analysis for audit.

🔬
Layered Analysis
Every scan stores a complete 11-layer evidence JSON in scans.layered_analysis_json. The Layered Analysis screen lets auditors drill into each forensic layer's raw output, matched signals, and score contributions.
📋
Structured Field Extraction
All extracted fields are persisted in document_extractions keyed by entity and file name. Payslips, bank statements, Form 16, offer letters, marksheets — each has a rich field schema surfaced here.
⚠️
Fraud Signal Review
Only signals that failed their check are shown — no noise from passed checks. Each signal carries a name, severity, description, and score contribution so analysts know exactly where to look.
📊
Cross-Document Comparison
Compare payslips across months — identity drift, net-pay drop spikes, account number changes, and period gaps are all detected and surfaced as named comparison signals with before/after values.
🔄
2-Level HITL Approval
Scans land in Review Scans as pending after a Bulk Save. A first reviewer approves, then a second reviewer signs off. Only fully approved scans are promoted to Document Intelligence. No silent auto-promotion.
📄
Downloadable PDF Reports
Every verified entity has a PDF audit report stored in PostgreSQL and retrievable via the REST API. The report contains the full verdict, evidence chain, extracted fields, and reviewer sign-offs.

How It Works

Upload. Analyse. Act —
in seconds

BaseTruth turns a raw document into a structured, explainable verdict in three steps.

01
Upload the document
Drop a PDF, image, or folder of mixed documents into the operator UI or POST to the REST API. BaseTruth snapshots the file into an evidence workspace and assigns a BT-reference number.
02
The pipeline fires
Eleven forensic layers run in parallel: OCR extraction, metadata analysis, arithmetic checks, image forensics, semantic validation, and domain-specific rules — simultaneously, not sequentially.
03
Evidence, not scores
You get a truth score, a named verdict (CLEAN / SUSPICIOUS / FORGED), and a full explanation of every signal — in JSON, Markdown, and a downloadable PDF audit report. Your analyst knows exactly why.
Get Started

Running in
under five minutes

Docker Compose is the fastest path. Python virtualenv works too. Your data never leaves your machine.

1
Clone & install
# Get the code
git clone https://github.com/maluskarhrishikesh-afk/BaseTruth
cd BaseTruth

# Create a virtual environment
python -m venv .venv
.venv\Scripts\activate

# Install all extras
pip install -e ".[ui,api,pdf]"
2
Or use Docker Compose
# Start the full stack
# (API + UI + PostgreSQL + MinIO)
docker compose up

# Everything is ready at:
✓ UI → http://localhost:8501
✓ API → http://localhost:8000
✓ Docs → /api/docs

# PostgreSQL + MinIO included
3
Scan your first document
# Scan a single document
python -m basetruth.cli scan \
  --input payslip.pdf

# Run the full UI
streamlit run \
  src/basetruth/ui/app.py

✓ Report saved to artifacts/
