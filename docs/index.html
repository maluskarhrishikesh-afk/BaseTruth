What It Does

A complete pipeline for
document truth

Every scan produces a named, scored, explainable verdict. No guesswork. No opaque models.

🔬
11-Layer Forensic Engine
PDF metadata, ELA error-level analysis, EXIF inspection, noise consistency, arithmetic checks, producer tool detection, font analysis, watermark integrity, and more — all in one pipeline.
📝
Intelligent OCR Extraction
PaddleOCR-powered extraction with LiteParse structure recovery. Deterministic parsers for marksheets (SSC/HSC/BE), payslips, and identity cards. Raw OCR markdown artifacts preserved for audit.
🆔
Identity Verification
Aadhaar QR decode, PAN OCR & Gemma4 extraction, selfie document-type check, and face-match with InsightFace — all running in parallel via a ThreadPoolExecutor for sub-second results.
📦
Bulk Scan & Classification
Upload a folder of mixed documents. Gemma4 batch-classifies by type, then dispatches forensics and field extraction to a ProcessPoolExecutor. Total runtime is bounded by the slowest document.
📊
Cross-Document Intelligence
Compare payslips across months — detect identity drift, net-pay drop spikes, and period gaps. Reconcile amounts and identities across different document types in the same case.
📋
Audit-Ready PDF Reports
Every scan produces a full PDF audit report stored in PostgreSQL, downloadable via REST API. Each signal carries a name, severity, score contribution, and plain-text explanation an analyst can read.
🧠
Universal Fraud Model
A unified machine learning engine trained on over 100,000 real-world fraud cases. Detects subtle expert-level edits, hidden white-text attacks, signature replacement, and metadata manipulation across all formats.
👥
Human-in-the-Loop Routing
Intelligently escalates borderline cases to investigators using an advanced confidence score logic. Seamlessly manage the review queue via our state-of-the-art Explainable AI dashboard.

How It Works

Upload. Analyse. Act —
in seconds

BaseTruth turns a raw document into a structured, explainable verdict in three steps.

01
Upload the document
Drop a PDF, image, or folder of mixed documents into the operator UI or POST to the REST API. BaseTruth snapshots the file into an evidence workspace and assigns a BT-reference number.
02
The pipeline fires
Eleven forensic layers run in parallel: OCR extraction, metadata analysis, arithmetic checks, image forensics, semantic validation, and domain-specific rules — simultaneously, not sequentially.
03
Evidence, not scores
You get a truth score, a named verdict (CLEAN / SUSPICIOUS / FORGED), and a full explanation of every signal — in JSON, Markdown, and a downloadable PDF audit report. Your analyst knows exactly why.
Get Started

Running in
under five minutes

Docker Compose is the fastest path. Python virtualenv works too. Your data never leaves your machine.

1
Clone & install
# Get the code
git clone https://github.com/maluskarhrishikesh-afk/BaseTruth
cd BaseTruth

# Create a virtual environment
python -m venv .venv
.venv\Scripts\activate

# Install UI + API + PDF support
pip install -e ".[ui,api,pdf]"
2
Or use Docker Compose
# Start the full stack
# (API + UI + PostgreSQL + MinIO)
docker compose up

# Everything is ready at:
✓ UI → http://localhost:8501
✓ API → http://localhost:8000
✓ Docs → /api/docs

# PostgreSQL + MinIO included
3
Scan your first document
# Scan a single document
python -m basetruth.cli scan \
  --input payslip.pdf

# Compare payslips across months
python -m basetruth.cli \
  compare-payslips \
  --input-dir ./payslips/

✓ Report saved to artifacts/
